# Momento2_Python

Este proyecto contiene scripts en Python para el análisis y procesamiento de datos de productos de un E-commerce.

## Estructura del proyecto
- `Analisis.py`: Script principal para cargar, limpiar, estandarizar y analizar los datos.
- `Funciones.py`: Módulo con funciones para manipulación de datos (cargar, limpiar, estandarizar, etc).
- `Data/productos.csv`: Archivo de datos de productos en formato CSV.

## Requisitos
- Python 3.x
- pandas
- numpy

Instala los paquetes necesarios con:
```bash
pip install pandas numpy
```

## Uso
1. Coloca tus archivos de datos en la carpeta `Data`.
2. Ejecuta el script principal:
   ```bash
   python Analisis.py
   ```

## Funcionalidades principales
- Carga de datos desde archivos CSV, Excel o JSON.
- Limpieza de datos (eliminación de nulos y duplicados).
- Estandarización de columnas (capitalización, eliminación de espacios y símbolos).
- Fusión de DataFrames para análisis comparativo.
